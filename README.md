# Credit Scoring Model Using Machine Learning

## Project Overview
This project predicts an individual's creditworthiness using historical financial data.

## Objective
To classify whether a customer is a good or bad credit risk.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn

## Algorithm Used
Random Forest Classifier

## Features
- Data Preprocessing
- Classification
- Accuracy Evaluation
- Precision, Recall and F1-Score
